# Readdict 阅读分页、连续模式与同步滚动修复设计

- 日期：2026-08-12
- 状态：已获视觉与交互设计批准，待书面规格审阅
- 范围：`SyncPage.qml`、阅读页顶栏与进度显示、竖向连续阅读、横向严格分页
- 技术边界：C++17、Qt 6.11.1（Core、Gui、Quick、QuickControls2）；Windows 10/11、Linux、macOS ARM
- 前序规格：`2026-08-12-kindle-navigation-design.md`

## 1. 问题与目标

当前实现存在 4 个已复现问题：

1. `SyncPage.qml` 的表单宽度未扣除垂直滚动条宽度。垂直滚动条出现后，内容宽度大于视口，Qt Quick Controls 会生成意外的水平滚动条；截图左上角的灰色小方块是其滑块。
2. 阅读顶栏保留 `Aa` 与「布局」，但二者只会跳到底部 Sheet 的同名标签，形成重复入口。布局 Sheet 在低窗口中内容被裁切；「更多」中的「阅读进度」错误地打开目录，没有控制阅读页左下角的进度显示。
3. 竖向模式只渲染当前章节。到达章尾后直接 `loadChapter(next)`，旧内容销毁、偏移复位，因此无法向上连续回看，且会在章界产生跳变。
4. 横向模式按字符数量估算段落分组。超高段落被放进页内纵向 `Flickable`，导致所谓横向分页仍需上下滚动，并可能因字体、窗口、富文本或图片实际尺寸与估算不同而出现溢出或空白。

本阶段目标：

- 同步页仅允许纵向滚动，不显示意外水平滚动条或其滑块。
- 顶栏采用已确认的紧凑排布；所有排版入口只保留在底部 Sheet。
- 「更多」可切换左下角的页数或百分比显示，默认页数；目录入口仍只在功能菜单中。
- 竖向模式在章节边界前后连续滚动，前后移动都保持视觉锚点。
- 横向模式严格一屏一页，页边界由 Qt 实际文本布局决定；不允许页内纵向滚动。

## 2. 已确认的交互与视觉决策

### 2.1 阅读顶栏

顶栏固定为紧凑工具栏：

- 左侧：返回图书馆。正常宽度显示「← 书库」；窄宽度只显示返回箭头。
- 右侧：笔记、书签、搜索、更多，按该顺序连续排列。
- 书签保持描边/填充两种状态。
- `Aa` 与「布局」从顶栏删除。主题、字体、布局、更多设置只在阅读区上下热区打开的底部 Sheet 中出现。
- 每个图标按钮保持固定的最小命中面积；只隐藏返回文案，不缩小按钮命中面积。

窗口最小尺寸保持 `800 × 600`。底部 Sheet 的标签栏和底部动作栏固定；内容区不足时仅内容区出现垂直滚动条。

### 2.2 阅读进度

阅读页左下角显示进度，默认格式为页数：

- 页数：`第 N / M 页`。`N` 与 `M` 是当前章节在当前窗口与排版参数下的实际视觉页号和总页数。
- 百分比：`书中 P%`。`P` 使用「当前章节索引 + 当前章节内视觉页比例」除以总章节数计算，取整并限制在 `0%` 至 `100%`。这是当前位置百分比，不读取书架的“历史最远进度”字段。
- `reading/progressDisplay` 保存为 `pages` 或 `percent`；缺失或非法值回退为 `pages`。
- Sheet「更多」使用单选分段控件切换该值，并显示当前格式的只读预览。它不再打开目录，也不承担翻页功能。
- 目录仍仅由顶栏「更多」菜单中的「目录」打开。

进度标签在正文上层、底部左侧固定，位于 TTS 条上方；底部 Sheet 打开时由 Sheet 遮罩覆盖，不与设置内容重叠。

## 3. 同步页滚动设计

`SyncPage.qml` 保留固定 Header 与页面级 `ScrollView`，但改为 Qt 官方的严格单轴尺寸约束：

- 表单内容宽度绑定 `syncScroll.availableWidth`，包括 Qt 在垂直滚动条可见时扣除的有效宽度。
- 显式将 `ScrollBar.horizontal.policy` 设为 `ScrollBar.AlwaysOff`。
- 页面级 `ScrollBar.vertical` 保持 `AsNeeded`，日志 `ListView` 的内部垂直滚动保持不变。
- 表单行的 `RowLayout` 必须在 `800 × 600` 与最小验收窗口中保持非负、非零的输入区宽度；不通过扩大内容宽度制造横向滚动。

这直接消除灰色方块的来源，而非以透明样式隐藏它。

## 4. 原生视觉页测量层

### 4.1 职责和边界

扩展现有 `ReaderTextHelper` 为阅读布局辅助层。它继续通过公共 `QQuickTextDocument` 获取每个只读 `TextEdit` 的实际 `QTextDocument`，不使用 Qt 私有头文件，不增加第三方依赖。

新增的 QML 可调用测量接口接收当前已挂载的段落项、目标视口高度和正文列坐标，返回稳定的视觉页映射：

```text
[
  { startY, endY, firstParagraph, firstTextPosition },
  ...
]
```

`startY` 与 `endY` 是正文列中的实际像素边界；`firstParagraph` 与 `firstTextPosition` 是该页首行的稳定锚点。QML 用该映射裁剪同一份正文列，不能复制、估算或重新分组段落。

测量规则：

1. 使用 `QTextDocument` 的文档布局和每个 `QTextBlock` 的 `QTextLayout` / `QTextLine` 实际行位置作为候选断点。
2. 结合段落项到正文列的映射坐标，生成章节内所有真实可见行的全局 Y 坐标。
3. 以每页可用高度为上限，选择最后一个完整可容纳的实际行作为页尾；下一页从下一行开始。
4. 图片段按视口高度约束等比缩放；单张图片永远不高于单页可用高度。图片前后是合法断点。
5. 极窄窗口、空章、空段落、无句子段落、富文本标题和行内图片都必须产生单调递增、无空页的映射。

Qt 官方 `QTextDocument`、`QTextLayout` 和 `QTextLine` 已提供实际富文本行布局、换行和行位置。该层读取已渲染的同一文档，保证测量结果与 QML `TextEdit` 的字体、行距、富文本和图片呈现一致；禁止再按字符数估算分页。

### 4.2 失效与性能

视觉页映射只在以下输入改变后重新计算：驻留段落窗口、字体族、字号、行间距、对齐、页边距、正文宽度或正文高度。

- 同一轮 QML layout 期间通过单次短延迟合并重算，避免每个 `implicitHeight` 更新都重新遍历。
- 测量只处理当前驻留窗口中已挂载的段落，不预渲染整本书。
- 页映射的计算不读写数据库、不更改阅读位置、不触发自动续章。
- 测量失败时保留上一份有效映射；无有效映射时显示第 `1 / 1` 页。横向模式禁用页面推进，竖向模式保留当前已渲染内容；两种模式都不能显示空白页或崩溃。

## 5. 竖向连续阅读

### 5.1 驻留窗口

竖向模式不再以“当前章节”作为渲染边界。`ReaderPage` 管理按书籍章节顺序排列的阅读窗口，`ReaderContent` 只渲染该窗口。

- 常态窗口目标为当前可见视口加上下各 `1` 个完整视口，合计 `3` 个视口高度；书籍首尾允许缺少一侧缓冲。
- 上方或下方剩余缓冲少于 `0.5` 个视口时，按完整段落追加，直到该侧缓冲达到 `1` 个视口或到达书籍边界。
- 某侧缓冲超过 `1.5` 个视口时，只回收远离视口的完整段落，回收到该侧保留 `1` 个视口；章节标题作为普通边界标记，不成为跳转页。
- 章节数据可以驻留在 C++/QML 数据模型中，但只有窗口内段落创建 QML 正文委托；长书不能随阅读时长线性累积正文委托。
- 章节加载失败时，在该章节位置插入现有可读错误占位；相邻章节仍可浏览。占位提供重试，不造成整个连续流失效。

### 5.2 章节激活与视觉锚点

窗口中的段落携带 `chapterIndex`、`chapterTitle` 与该章内段落索引。阅读视口中线首次进入另一个章节时：

1. `ReaderContent` 发出章节激活请求。
2. `ReaderPage` 更新 `Books.currentChapter`、当前章节标题、TTS 句子列表、书签状态与当前位置持久化，但不重置 `contentY`。
3. 插入或回收窗口前保存顶部可见段落的稳定键 `{ chapterIndex, paragraphIndex }` 及该段相对视口的 Y 偏移。
4. 布局完成后定位同一稳定键，再以保存的相对偏移恢复 `contentY`。

因此从上一章向下、从下一章向上跨越边界时，屏幕上的文字位置保持连续。TTS 仅朗读激活章节；播放/暂停期间维持既有“滚动不自动换章”门控。

手动滚动到章节末尾不会再立刻销毁当前章节。自动续章只在用户明确启用自动续章、已到真实内容末端且下方窗口尚未预取到下一章时请求加载；预取到的下一章应直接连续出现。

### 5.3 位置与交互

- `progress/<bookId>` 继续持久化当前激活章节索引。
- 新增 `progress/anchor_<bookId>`，值为 `{ chapter, paragraph, offset }`：`paragraph` 是章节内段落索引，`offset` 是该段相对视口顶部的像素偏移。恢复时先定位该锚点，再恢复偏移。
- 既有 `progress/scroll_<bookId>` 继续保存该章内局部 Y 偏移，供旧版本和缺少新锚点时兼容恢复；新锚点存在时优先使用它。不得把驻留窗口的全局 `contentY` 作为跨章节恢复位置。
- 方向键上/下和鼠标滚轮在连续模式中只移动视口，不在章界转换为跳章。
- 左/右键仍按既有语义请求上一章/下一章；这属于显式章节导航，不影响连续滚动。
- 顶部/底部热区继续用于打开或关闭阅读设置，不因缓冲窗口改变。

## 6. 横向严格分页

### 6.1 呈现模型

横向模式以当前激活章节为单位。正文保留一份实际布局后的段落列，外层使用固定大小且 `clip: true` 的单页视口。

- 视觉页映射提供每页的 `startY` 和 `endY`。
- 视口只显示 `startY` 至 `endY` 的内容，并将同一正文列偏移到当前页起点。
- 单页视口宽高严格等于可用阅读区域。外层只允许水平方向输入；页面内不包含纵向 `Flickable`、纵向滚动条或可滚动的子页面。
- 页内没有完整可容纳的下一页或上一页内容；翻页后才改变当前页偏移。
- 页面切换保持 `300 ms` 水平出入动画：先以不透明纸色遮住离场后的空区，当前页完全离场后切换正文偏移，再让新页进入。任一动画帧最多只显示一页正文，不暴露相邻页文本。

点击左右边缘、鼠标滚轮、方向键和 PageUp/PageDown 都调用统一的 `pagePrev` / `pageNext`。页首再次后退请求上一章，页末再次前进请求下一章；自动重复按键仍不得连续跨章。

### 6.2 严格边界

- 字体、行距、页边距、窗口宽高任一变化后，重新由实际行位置构建页映射，当前页按锚点恢复并钳制。
- 段落或句子超过一页时，断点按真实行边界切分到下一页；不允许将整段留在当前页后通过内部上下滚动阅读。
- 选中文本、划线、笔记和 TTS 高亮仍使用原段落与全局句索引。视觉分页只改变裁剪视口，不复制或拆分高亮数据。
- 当前页变更时，进度标签更新为当前章节的实际页号；百分比按当前页在该章中的比例更新。
- 搜索与笔记跳转根据命中段落的实际 Y 坐标查找所属视觉页，再调用统一翻页入口。

## 7. 底部 Sheet 与更多设置

`KdBottomSheet` 保持独立滚动内容区：

- `body` 高度为窗口高度的既有比例，但最低高度、标签栏和主题动作栏不被内容挤压。
- 面板 `implicitHeight` 大于内容视口时，`panelScroller` 成为唯一垂直滚动容器，滚动条 `AsNeeded`；字体、布局、更多面板的交互控件不得被该容器截获或遮挡。
- `LayoutSheet` 的方向、页边距、行间距和对齐全部可滚动到达。
- `MoreSheet` 保留自动续章和深色跟随；将旧的可点击「阅读进度」目录行替换为页数/百分比单选控件与预览。目录没有第二入口。

## 8. 错误处理与兼容性

- 现有 `reading/pageMode` 继续使用 `scroll` 与 `paged`，不迁移为新 token。
- 新的 `reading/progressDisplay` 只接受 `pages`、`percent`；其它值回退 `pages` 并在下一次用户选择时覆盖。
- 无章节、无段落、未布局完成、窗口尺寸为 `0`、字体不可用、图片不可读时不计算非法页偏移；使用当前已显示内容或安全的 `1 / 1` 进度。
- Qt 布局辅助层只使用 `Qt6::Gui`、`Qt6::Quick` 的公共 API。不得引入 macOS、Windows 或 Linux 专有 API，不新增外部库。
- 不能以隐藏滚动条、阈值提前换章或字符数估算来掩盖问题。

## 9. 测试与验收

### 9.1 同步页

- 在内容超高时，页面只出现垂直滚动条；`ScrollBar.horizontal.policy` 为 `AlwaysOff`，有效水平滚动范围为 `0`。
- 反复滚动后，首个表单标签左侧不出现滚动条滑块或残留项。
- 返回 Header 固定可见；日志保留独立可用高度和内部垂直滚动。

### 9.2 顶栏、Sheet 与进度

- 顶栏不再暴露 `Aa` 和布局按钮；保留返回、笔记、书签、搜索、更多。
- 正常和窄宽度下，右侧图标顺序、命中面积、返回文案收缩规则正确，不重叠。
- 最小窗口 `800 × 600` 下打开布局 Sheet，最后一个对齐控件可通过内容滚动到达；标签栏保持固定。
- 默认读取/写入 `reading/progressDisplay=pages`；切换后阅读页左下角立即在页数/百分比间切换，不打开目录。
- 页数标签对横向当前页和竖向实际视觉页变化；百分比限制在 `0%` 至 `100%`。

### 9.3 竖向连续阅读

- 穿越章末后，下一章内容与上一章连续；不发生 `contentY=0` 重置或白屏。
- 从下一章向上滚动可无跳变回到上一章。
- 插入与回收窗口内容后，保存的顶部可见段落及其相对视口位置保持不变。
- 驻留内容不超过目标缓冲范围；长书不随阅读时长线性累积 QML 段落委托。
- 显式左右键章节导航、TTS 暂停门控、自动续章开关和滚动位置恢复仍遵守既有契约。

### 9.4 横向严格分页

- 每个页面视口宽高等于阅读区域；外层无纵向滚动，页内不存在 `Flickable` 或纵向滚动条。
- 使用长句、富文本标题、行内图片、超长段落、不同字号、行距、边距和窗口尺寸验证：每页只显示可容纳的完整实际文本行，剩余内容仅在下一页出现。
- 相邻页不同时显示；右/下和左/上按键、滚轮、左右边缘点击均按一页推进或回退。
- 页首/页末再次翻页的章节切换只发生一次；自动重复按键不跨越多个章节。
- 搜索、笔记跳转、文本选择、划线和 TTS 高亮可定位到对应严格页，不丢失段落或句索引。
- 重新调整窗口或排版后，重新分页且当前阅读锚点保持；不出现负偏移、空页、裁切半行或页数振荡。

### 9.5 构建与平台

- 新增 C++ 帮助类和现有 QML 测试纳入 CMake；使用 Qt 6.11.1 的现有组件完成构建。
- macOS ARM 运行完整 `ctest` 与视觉冒烟；代码不包含平台专有分支。
- Windows 10/11 与 Linux 使用相同的 Qt 公共 API 编译路径；若目标平台缺少 Qt 组件，停止并报告，不自行安装。

## 10. 非目标

- 不改 EPUB、MOBI、FB2、TXT、Markdown 解析器的输入格式或数据库 schema。
- 不重写 PDF 阅读器。
- 不改变 WebDAV 同步协议、凭据存储或同步内容选择。
- 不新增第三方排版库、WebEngine、系统原生分页 API 或后台云服务。
- 不将整本书预渲染到内存，也不通过整段字符数估算分页。
