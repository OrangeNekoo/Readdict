# Readdict Kindle 风格导航优化设计

- 日期：2026-08-12
- 范围：第一阶段交互流程与导航
- 技术边界：Qt 6.11.1、C++、QML；Windows 10/11、Linux、macOS ARM

## 1. 背景与目标

Readdict 当前已经有主页、书架、设置、统计、同步和阅读器页面，但主导航、深层页面返回、阅读器边界和页面状态由多个 QML 入口共同影响，容易出现重复压栈、底部导航状态与实际页面不一致、返回后筛选或滚动状态丢失等问题。

本阶段目标是以 Kindle 参考界面的信息层级为基准，统一主页、图书馆和阅读层的导航行为，修复可复现的导航逻辑错误。允许修复导航所依赖的最小后端状态问题；不改变书籍解析、导入规则、数据库业务规则、同步协议或阅读内容格式。

## 2. 已确认的视觉与交互方向

- 主导航只保留“主页”和“图书馆”。
- 主页采用顶部状态区、搜索入口、最近阅读横向书籍卡片和底部主导航。
- 图书馆采用顶部搜索入口、筛选/排序控制和书籍卡片网格。
- 书籍卡片采用 Kindle 参考图的克制边框、信息层级和阅读状态表达。
- 桌面窗口允许卡片按可用宽度自适应排列，但不新增侧边栏，不引入第三种主导航。
- 设置、统计、同步、导入和关于从右上角菜单进入。
- 阅读器和 PDF 阅读器作为独立阅读层；阅读时隐藏主页/图书馆底部导航。
- 阅读页顶部工具栏默认隐藏，点击阅读区域后显示。

## 3. 导航架构

`Main.qml` 是唯一的导航协调者，继续使用现有 `StackView` 作为页面容器。主页面通过稳定的 `navId` 标识主导航上下文：`home` 和 `shelf`。统计、同步、设置及设置子页面属于辅助层； EPUB、MOBI、FB2、TXT、Markdown 和 PDF 阅读页面属于阅读层。

导航状态至少包含：

- 当前栈顶页面。
- 当前主导航上下文 `currentNavId`。
- 主导航是否可见 `navVisible`。
- 进入阅读层前的主导航上下文。

所有主导航入口（底部标签、菜单中的主页/图书馆入口、主页和图书馆内部的跳转）必须调用统一导航函数。页面不得自行修改底部标签选中状态。

主导航切换规则：

1. 目标是当前主页面时不产生新栈项。
2. 从一个主页面切换到另一个主页面时，清除当前主导航下的辅助层和阅读层。
3. 目标主页面只保留一个实例，避免重复压栈。
4. 切换完成后由栈状态统一计算 `currentNavId` 和 `navVisible`。
5. 阅读层和 PDF 阅读层始终隐藏底部主导航。
6. 辅助页面从右上角菜单进入；从辅助页面返回时回到进入前的主导航上下文。

## 4. 页面与数据流

### 4.1 主页

主页请求最近阅读数据并显示横向书籍卡片。点击书籍卡片进入对应阅读层。主页到统计页面的入口保留，但统计页面退出后返回主页，不改变主导航上下文。

### 4.2 图书馆

图书馆显示全部书籍，并提供搜索、筛选和排序。搜索栏的输入只驱动图书馆搜索状态；从主页开始输入搜索时可切换到图书馆，但切换必须通过统一导航函数完成。切换前后的搜索文本、筛选条件和滚动位置由页面状态保留，除非用户明确清除。

卡片布局使用响应式网格或等价的 QML 布局：卡片宽度和列数由窗口可用宽度计算，不建立侧边栏，不让文本、进度标识或操作按钮撑大卡片导致布局跳动。

### 4.3 阅读层

打开非 PDF 书籍进入 `ReaderPage.qml`，PDF 进入 `PdfReaderPage.qml`。阅读层保存进入前的主导航上下文。返回操作优先关闭当前阅读层，恢复此前主页或图书馆；不得回到一个重复的主页面实例。

阅读工具栏显示/隐藏只改变阅读层内部可见状态，不改变主导航状态。工具栏、目录、字体、布局和更多设置等控件关闭后仍留在当前阅读位置。

### 4.4 右上角菜单

菜单统一提供：导入书籍、阅读统计、同步、设置、关于。每个菜单项只对应一个导航或弹窗入口。菜单关闭与页面返回不能额外压入相同页面。

## 5. 错误处理与状态保护

- 找不到目标页面或目标书籍时，导航函数保持当前页面，不写入部分导航状态。
- 书籍格式缺失或不支持时，不进入错误的阅读器；显示现有错误反馈，并保留原页面。
- 页面创建失败或数据请求返回空值时，保持主导航选中状态与实际栈顶页面一致。
- 快速重复点击主导航、菜单项或返回按钮不得造成重复页面。
- 阅读层返回期间若数据刷新，不能清除用户当前主页面的搜索、筛选和滚动状态。
- 平台相关的窗口关闭、键盘 Escape/Back 和鼠标操作必须映射到同一个返回语义；不得依赖平台专有 API。

## 6. 测试与验收

### 6.1 QML/集成行为

覆盖以下可观察契约：

- 启动进入主页，底部仅显示主页和图书馆两个主导航项。
- 在主页与图书馆之间重复点击切换，栈深度不无限增长，选中状态始终匹配栈顶页面。
- 从主页、图书馆分别打开统计、同步、设置，再返回，均回到原主导航上下文。
- 从主页和图书馆打开 EPUB/PDF 阅读器，底部导航隐藏；返回后恢复进入前页面及其搜索/筛选上下文。
- 快速重复点击菜单项和返回按钮不会创建重复辅助页或重复阅读页。
- 搜索输入从主页切到图书馆后，搜索文本和结果状态正确传递。
- 在不同窗口宽度下，书籍卡片网格不重叠、不溢出，文本和进度标识不改变卡片尺寸。

### 6.2 跨平台检查

在 macOS ARM 上完成完整导航场景；使用 Qt 6.11.1 的 Windows 10/11、Linux 构建配置检查，验证不引入 macOS、Windows 或 Linux 专有导航依赖。若构建或运行所需 Qt 组件缺失，停止并报告，不自行安装。

## 7. 非目标

- 不重写 EPUB、MOBI、FB2、PDF 解析器。
- 不改变数据库 schema、同步协议或导入格式支持范围。
- 不新增账户、云端服务、推荐系统或侧边栏。
- 不把统计、同步、设置提升为底部主导航。
- 不在本阶段实现启动恢复上次页面、系统文件关联或新的阅读功能，除非现有导航缺陷证明其为必要依赖。
